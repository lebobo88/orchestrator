# Comparison research

Define the decision, options, constraints, and criteria before scoring. Use a sourced comparison matrix that records each criterion, weight when material, option evidence, tradeoff, and confidence. Separate facts from assumptions, test the strongest alternative interpretation, state what would change the recommendation, and avoid false precision. Conclude with a bounded recommendation, non-recommendation conditions, validation steps, and required user approvals.
