# Root-cause research

Start with observed symptoms, impact, timeline, reproduction conditions, and available evidence. Form multiple competing hypotheses; seek evidence that could disprove each one. Trace causal chains rather than stopping at the nearest symptom. Report root-cause confidence, contributing conditions, unknowns, prevention options, containment/recovery, and a validation plan that would confirm or refute the conclusion. Do not prescribe an implementation beyond the user-approved scope.
