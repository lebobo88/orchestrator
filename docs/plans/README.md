# Approved plans

Scribe writes one non-basic task plan at `docs/plans/<slug>.md` from Planner's direct `PLANNING_HANDOFF`. A plan remains a draft until the user explicitly approves it. T1 may implement only an approved, non-stale plan.

See [PLAN-CONTRACT.md](../PLAN-CONTRACT.md) for routing, ownership, approval, and stale-plan handling.
